# ✨ Features

> Complete feature overview for users and developers.

---
## 💸 Money management

- 💰 Accounts and balances.
- ➕ Income records.
- ➖ Expense records.
- 🔁 Transfers.
- 🧾 Transaction list and filters.
- 🏷️ Categories with enable/disable settings.
- 📊 Analytics and category watch.
- 🏦 Loans and loan payments.
- 📅 Budgets and reminders.

## 🎨 UI/UX

- 🪟 Modern rounded bottom-sheet modals.
- 🌗 Dark/light support.
- 🎨 Accent color support.
- 👤 Profile icon/avatar support.
- 📱 Mobile-first layout.
- 🔔 Notification panel.

## 🔐 Privacy/security

- 🔒 PIN/lock utilities.
- 💾 Local storage.
- 🧾 Encrypted local backup.
- ☁️ Encrypted cloud backup payload.

## 🔥 Login and sync

- 👤 Firebase Google login.
- 🪪 Firebase UID identity.
- ☁️ Cloudflare Workers KV backup.
- 🔁 Same Google account multi-device restore.
- ⚙️ Optional automatic KV backup toggle.

## 🧰 Developer features

- 🏗️ GitHub Actions APK build.
- 📦 GitHub Releases updater.
- 📚 Modern docs with book navigation.
- 🧪 Worker and release checks.
