# 📘 User Guide

> How to use CashNest X login, backup, restore, and money tracking safely.

---
## 🚀 First launch

1. Open CashNest X.
2. Set your currency and basic profile.
3. Add accounts.
4. Add income/expense/transfer records.
5. Optional: connect Google account for cloud sync.

## 👤 Google account

Open:

```text
Settings → Firebase Google Account
```

Tap to sign in. CashNest X uses Google login through Firebase only for identity.

## ☁️ Cloud backup

Open:

```text
Settings → Cloudflare KV Backup
```

Tap backup to save encrypted data to your user backup key.

## 🔁 Restore on another device

1. Install same APK on another phone.
2. Sign in with the same Google account.
3. Tap **Restore KV Backup**.
4. Confirm local data replacement.

## 💾 Local backup

Use local backup when you want offline backup without internet. Keep backup files safe because they contain your encrypted ledger data.

## 🧾 Export

Use export options for readable summaries/reports. Export files are separate from cloud sync.

## ⚠️ Restore warning

Restore replaces current local data with backup data. Create a local backup first when unsure.
